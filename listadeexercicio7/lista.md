
 Observação : todos os exercícios abaixo devem ser feitos três vezes, sendo uma com "while", uma com "do while" e uma com "for". 


1) Crie um algoritmo que exibe números do 0 a 100 com o laço de repetição "faça enquanto..."


2) Crie um algoritmo que exibe os números pares entre 0 e 100 com o laço de repetição "faça enquanto..."


3) Crie um algoritmo que exibe os números ímpares entre 1 e 99 com o laço de repetição "faça enquanto..."


4) Crie um algoritmo que pede ao usuário para que ele digite um número. Assim, se o número digitado pelo usuário for zero, a execução do programa se encerra, contudo se ele digitar outro número, o programa executa novamente.


5) Crie um algoritmo que pede para o usuário digitar quinhentos números e faz uma média aritmética entre eles. Aliás, faça utilizando o laço de repetição "faça enquanto".


6) Crie um algoritmo que receba um número e exibe a tabuada dele.


7) Crie um algoritmo que receba dois números e calcule o resto de divisão entre eles. Observação: faça sem o operador de módulo e garanta que o primeiro número seja sempre maior que o segundo.


8) Crie um algoritmo que calcule o fatorial de um número digitado pelo usuário.


9) Crie um algoritmo que emule um menu de estoques de um produto. Sendo assim, o menu deve ter quatro opções: (1) visualizar estoque, (2) adicionar um produto ao estoque, (3) remover um produto do estoque e (4) encerrar programa. Dessa forma, se o usuário quiser visualizar o estoque (1), demonstre quantas unidades do produto o estoque contém; se o usuário quiser adicionar um produto ao estoque (2), adicione um produto ao estoque; se o usuário quiser remover um produto do estoque (3), remova um produto do estoque; se o usuário quiser encerrar o programa (4), finalize-o. Aliás, lembre-se que o programa só pode encerrar quando o usuário acessar a opção "encerrar programa". Fora isso, o programa continua rodando infinitamente.


10) Crie um algoritmo que receba o valor da base e expoente de uma potenciação e que, em seguida, realiza a operação e exibe o resultado. Aliás, não utilize bibliotecas matemáticas ou operadores de potência para elaborar este exercício (use apenas laços de repetição).


11) Crie um algoritmo que recebe nome, idade e sexo de uma quantidade indeterminada de pessoas, considerando que sempre que o algoritmo receber dados de um usuário, deve-se imprimir tais dados na tela e, em seguida, solicitar os dados do próximo usuário, que em seguida serão imprimidos também... (e o processo se repete...). Por fim, caso o nome de algum usuário seja igual a "cansei", a senha seja igual a "43aB" e o sexo seja igual a "K", finalize o programa.


12) Faça um algoritmo que leia uma quantidade indeterminada de números reais maiores que zero. Assim, se o usuário digitar o número zero, encerre as entradas e exiba quantos números foram inseridos pelo usuário e qual é o valor da média aritmética entre eles.


13) Faça um algoritmo que receba uma quantidade indeterminada de números reais. Assim, caso o usuário digite o número zero, encerre o algoritmo e exiba quais foram o maior e menor número digitados por ele. Aliás, obrigue o usuário a digitar, no mínimo, 5 números.


14) Crie um algoritmo que recebe um e-mail e uma senha. Caso o e-mail seja igual a "joaquim.ramos@gmail.com" e a senha seja igual a "kK3Kk", exiba na tela "usuário logado". Caso tais credenciais sejam inválidas, emita uma mensagem de erro e peça para ele digitar a senha novamente, considerando que ele possui um limite de cinco tentativas para acertar as credenciais. Por fim, caso ele não acerte em até cinco vezes, exiba "usuário bloqueado" e encerre o programa.


15) Crie um algoritmo que recebe um valor em segundos e retorna o seu equivalente em horas, minutos e segundos.

Exemplo: 

Entrada: o usuário digita 9471 segundos.

Saída:
- Horas: 2;
- Minutos: 37;
- Segundos: 51.
